# Favicon Setup

To add a favicon to your project:

1. Create a `favicon.ico` file (16x16, 32x32, or 48x48 pixels)
2. Place it in the `public/` directory
3. The layout already references it: `<link rel="icon" href="/favicon.ico" />`

You can generate a favicon using:
- [Favicon.io](https://favicon.io/)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- Or any image editor

For Connection.cv, consider using a "C" or connection/networking icon.
